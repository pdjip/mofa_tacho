# Arduino Mofa Tacho

## Voraussetzung
- Platform IO
- EEZ Studio

## Anleitung
1. Öffne Projekt in EEZ Studio ([mofa.eez-project](mofa.eez-project))
2. Drücke Build / Bauen und lasse den die C Datein bauen
3. Kompiliere und lade neue firmware über Platform IO hoch
   1. pio run -t upload -e giga_r1_m7
